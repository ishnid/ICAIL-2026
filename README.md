# Persuadability and LLMs as Legal Decision Tools

This repository stores all code, data, prompt templates, prompts and statistics relating to the [ICAIL 2026](https://site.smu.edu.sg/icail-2026) submission named "Persuadability and LLMs as Legal Decision Tools".

If this paper is accepted, this repository will remain available, albeit moved to a non-anonymous repository linked to one of the authors.

## Contents

### Code

- `persuasion_utils.py`: utility functions (e.g. for prompt generation).

Contains several subfolders:

- `cleaning`: scripts to extract plain text from model outputs (not all models require cleaning).
- `local-prompting`: scripts that were run locally on a Slurm-controlled HPC cluster to prompt locally-run LLMs.
  - `judgment_job.sh`: batch script to invoke Python scripts via Slurm scheduler.
  - `judge_*.py`: 
- `remote-prompting` Jupyter notebooks used for accessing LLMs via APIs:
  - `advocates.ipynb`: prompt advocate models to generate arguments.
  - `judgment.ipynb`: prompt judge models to obtain decisions
- `processing`: various scripts for processing outputs:
  - `generate_stats.py`: conducts most of the statistical analysis, `outputting judge_model_stats.csv`, `argument_vs_noargument_stats.csv`, `thinking_vs_nothinking_stats.csv`, found in the `stats` folder.
  - `generate_wins_tables.py`: generate a stats table for an individual judge model (output found in the `stats/wins-arguments` and `stats/wins-noarguments` folders).
  - `generate_stats_arguments_vs_noarguments.py`: generate statistics for judging advocates against themselves with and without access to original arguments (output is `judge_model_stats_arguments_vs_noarguments.csv` in the `stats` folder).
  - `geneate_outcome_file.py`: parse the ouputs of the judge models to create an "outcomes" file (contained in the `data/outcomes-arguments`, `data/outcomes-noarguments`, `data-arguments-vs-noarguments` files).
  - `generate_judge_prompts.py` generate the prompts to be sent to the judges for the primary scenario (different advocate models against each other)
  - `generate_judge_prompts_arguments_vs_noarguments.py`: generate the prompts to be sent to the judges for the scenario where the same model is used as the advocate, with and without access to original arguments.

### Data

Several data filenames end in `_arguments` or `_noarguments`. The former as based on advocate arguments that had access to the original arguments presented in the real case. The latter are based on advocate arguments that did not have such access.

Contains several subfolders:

- `advocate-outputs`: arguments generated by advocate models. Those ending in `_arguments.csv` had access to the original arguments prented in the case. Those ending in `_noarguments.csv` did not.
- `judgments-arguments` and `judgments-noarguments`: output of judge models.
- `judgments-arguments-vs-noarguments`: judge model outputs for experiment using the same advocate models against themselves, with and without access to original arguments.
- `outcomes-arguments` and `outcomes-noarguments`: outcomes extracted from judgment files (i.e. the preferred party chosen by the judge models for each scenarios).
- `outcomes-arguments-vs-noarguments`: judge model outcomes (i.e. preferred chosen party) for experiment using the same advocate models against themselves, with and without access to original arguments.

Files:

- `all_outputs.csv`: concatenation of all output files for the primary experiment (different competing advocates)
- `all_outputs_arguments_vs_noarguments.cs`: concatenation of all output files for the experiment using the same advocate models against themselves, with and without access to original arguments.

### Statistics

Contains subfolders:

- `wins-arguments` and `wins-noarguments`: statistics generated on a per-judge-model basis.
- `wins-arguments-vs-noarguments`: statistics for experiment using the same advocate models against themselves, with and without access to original arguments.

Individual CSV files:

- `judge_model_stats.csv` - main page of stats for each judge model, which the following columns:
  - **Max_persuadability**: maximum pairwise persuadability from any pair of advocates (|m1-m2|/2n)
  - **Max CI low**: lower bound of confidence interval around the maximum pairwise persuadability - binomial confidence interval based on the proportion of trials won by the stronger advocate, less 0.5.
  - **Max CI high**: upper bound of confidence interval around the maximum pairwise persuadability - binomial confidence interval based on the proportion of trials won by the stronger advocate, less 0.5.
  - **Population persuadability**: population persuadability metric (sum for all pairs of |m1-m2|/2n_pop
  - **Chi-2 p-value**: p-value for a chi-squared test between win distribution and expected win distribution for this judge (using scipy.stats.chisquare)
  - **Significant**: true iff Chi-2 p-value < 0.05
  - sequence of pairwise metrics (advocate pairs in title, namely):
    - **pairwise persuadability** for this pair of advocates
    - **lower bound** of binomial confidence interval for this pair
    - **upper bound** of binomial confidence interval for this pair
  - **Proportion of biased cases**: proportion of cases where the judge had a significant preference for one party
  - **Proportion of biased cases favouring Party 1**: proportion of cases with significant preference for this party where Party 1 was the preferred winner
  - **Chi-2 jurisdictions**: p-value for chi-squared test to check for significant differences in the distribution of advocate wins across jurisdictions.
  - **Significant jurisdictions**: above statistic is < 0.05
  - **J0, J1, J2** - population persuadability values for each jurisdiction, with this judge (J0: US, J1: England and Wales, J2: Ireland).

- `judge_model_stats_arguments_vs_noarguments.csv` - main page of stats for the judge models that were asked to decide between instances of the same advocate model pitted against itself (with and without access to the original arguments). Fields are similar to the judge_model_stats.csv file above.

- `argument_vs_noargument_stats.csv` - comparison of same judge models deciding between advocates with and without access to original arguments
	- **Argument judge**: name of the judge who had access to the arguments
	- **Noargument judge**: name of the judge who did not have access to the arguments
	- **Argument population persuadability**: (same as in previous sheet) population persuadability for the judge who had arguments
	- **Noargument population persuadability**: (same as in previous sheet) population persuadability for the judge who did not have arguments
	- **Chi-2 p-value**: chi-squared p-value between the with-arguments and without-arguments distributions (using scipy.stats.chi2_contingency)
	- **Significant**: true iff Chi-2 p-value < 0.05

- `thinking_vs_nonthinking_stats.csv` - comparison of related models with thinking/reasoning (or higher thinking/reasoning) vs no thinking/reasoning (or lower thinking/reasoning)
	- **Thinking judge**: name of the judge with higher thinking budget or thinking enabled
	- **Nothinking judge**: name of the judge with lower thinking budget or thinking disabled
	- **Thinking population persuadability**: (same as in previous sheets) population persuadability for the 'thinking' judge.
	- **Nothinking population persuadability**: (same as in previous sheets) population persuadability for the 'non-thinking' judge.
	- **Chi-square p-value**: chi-squared p-value between the with-thinking and without-thinking distributions (using scipy.stats.chi2_contingency)
	- **Significant**: true iff Chi-square p-value < 0.05
- `all_outcomes.csv` - all the outcomes of every judgment - all stats are extracted from this
- `all_outcomes_arguments_vs_noarguments.csv` - all the outcomes of every judgment where we are pitting advocate models against themselves with and without access to the original arguments.
